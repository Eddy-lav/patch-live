    Imprimer ou faire un PDF
    Dans la fenêtre d'impression, choisis « Enregistrer au format PDF » pour faire un PDF. Si rien ne s'ouvre, prends le fichier à imprimer : il s'ouvre dans n'importe quel navigateur et s'imprime de la même façon.

    Affecter une plage de sources Sources

    Les listes de boîtier et de stage rack ne proposent que les entrées libres. Pour prendre une entrée occupée, déplace d'abord la source qui l'utilise.

    Clavier : ↑ et ↓ (ou Entrée) changent de ligne dans la même colonne, Tab et Maj+Tab changent de colonne. Sur une liste d'entrées, Alt+↓ ou Espace l'ouvre. Dans Micro, Pied ou Musicien, les suggestions s'ouvrent quand tu tapes ou cliques ; ↑ et ↓ les parcourent, Entrée choisit. Sélection : clic sur le N°, Maj+clic pour une plage, Cmd ou Ctrl+clic pour ajouter une ligne, Échap pour tout désélectionner.

    Ears HF ou filaires, wedges, subs, sides, envois FOH… Les listes ne proposent que les sorties et les liaisons libres. Clic sur le N° pour sélectionner (Maj+clic : une plage), puis « Patcher dans l'ordre ».
    Patcher les sorties dans l'ordre Sorties
    Un tableau par modèle d'appareil : micros (émetteurs), ears (récepteurs), Spectera SEK… Le nom du modèle se modifie directement. Clic sur le N° pour sélectionner des lignes (Maj+clic : plage) et leur donner la même valeur.
    Une colonne par boîtier, rangée par côté de scène. Touche une source pour la retrouver dans le master. « Dépatcher… » libère une plage d'entrées d'un boîtier (les sources restent dans le master).

    Le patch vu depuis chaque stage rack ou équipement I/O, un trait sépare les cartes ou les ports. Chaque ligne se modifie comme dans le master (micro, pied, musicien, boîtier, entrée…). Tape un nom dans une case libre pour y mettre une source : elle est créée, ou reprise si elle n'a pas encore d'entrée ; Entrée passe à la case libre suivante. Les sources ajoutées avec « + Source » attendent dans « Sources sans entrée » en bas. Sélection : clic sur le N°, Maj+clic pour une plage, Cmd ou Ctrl+clic pour ajouter une ligne.

    Dossier

    Le nom du dossier et la salle du jour se modifient en haut de la page. La couverture se règle depuis « Ajouter une couverture », tout en haut.

    Stage racks et I/O

    Stage racks, mais aussi DD4MR, Orange Box ou tout équipement de la loop : choisis le format « Ports nommés » pour décrire ses ports (MADI 1, Dante, DMI…) avec leur nombre de canaux. Rattache chaque équipement à sa console. Si les consoles (FOH, monitor, broadcast ou autre) ne partagent pas les stages, le master affiche une colonne de stage rack par console ; « Partagé » sert à toutes.

    Occupation des stage racks

    Une case par entrée et par sortie, remplie quand elle est utilisée. Passe la souris sur une case (ou touche-la) pour voir ce qui y est patché et câblé.

    Boîtiers de sous-patch

    Le type de multi donne le nombre d'entrées par défaut (12N = 12 liaisons, 20H = Harting 20 liaisons). Tu peux le changer dans la colonne Entrées, ou choisir « Autre ».

    Liaisons

    Horloge

    Chaque console du dossier apparaît ici : choisis son modèle et ses entrées et sorties locales se déclarent toutes seules. Note dessus les AES, inserts, effets et talkback. « + Insert » ajoute le départ et le retour d'un coup.
    La console de com est une console du dossier : choisis son modèle et ses locaux se déclarent tout seuls ; ses stage racks se règlent dans Réglages racks. Note aussi les liaisons 4 fils entre régies.

    Les consoles, les racks, les appareils HF et les éléments du synoptique apparaissent tout seuls, rangés par réseau. Les HF sont mis ensemble sur « Contrôle HF » ; pour les autres, écris le réseau de chaque appareil (Dante primaire, contrôle…). « + Appareil » ajoute un switch, un ordinateur ou une borne Wi-Fi. Une adresse en double sur le même réseau est signalée en rouge.

    Numéroter d'un coup

    Choisis un réseau (ou un type d'appareil) : ses appareils sans adresse prennent les suivantes, dans l'ordre du tableau, en sautant celles déjà prises. Fais-le une fois par réseau.

    Chaque déplacement d'entrée est noté avec la date et la salle du jour.
